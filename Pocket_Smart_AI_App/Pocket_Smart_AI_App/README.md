# PocketSmart AI

PocketSmart AI is a Generative AI powered budget and recommendation assistant.

It provides:

- Home Interior Planner
- Party Budget Planner
- Jewelry Budget Planner
- User registration
- Login/logout
- JWT authentication
- Recommendation history
- Gemini AI integration
- Optional jewelry outfit image analysis
- Budget-aware fallback recommendations

## Technology

- Python
- FastAPI
- SQLAlchemy
- SQLite
- Jinja2
- JavaScript
- HTML
- CSS
- Google Gemini
- JWT
- Pydantic
